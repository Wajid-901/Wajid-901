## Featured Projects

### [Unfazed](https://github.com/Wajid-901/Unfazed) · [Live Demo](https://unfazed-umber.vercel.app/)
Practice management SaaS for therapists and clients: appointment booking, payments, client CRM, and session management.
- Dual-role JWT authentication (therapist and client) with a secure invite-token onboarding flow
- Public booking flow with therapist approval and time-limited activation emails
- Razorpay integration: order creation, signature verification, webhooks, and invoice generation
- Strict therapist-client data isolation; 10+ Mongoose models with compound and sparse unique indexes

**Stack:** React · Node.js · Express · MongoDB · Razorpay

### [HireFlow](https://github.com/Wajid-901/Hire-Flow) · [Live Demo](https://hire-flow-six-theta.vercel.app/)
Job application tracker with a dashboard, analytics, and calendar, deployed on Vercel + Render + MongoDB Atlas.
- JWT authentication with bcrypt hashing and hashed, time-limited password-reset tokens
- Ownership-enforced REST APIs that return 404 (not 403) to prevent data-existence leakage
- Hardened with Helmet.js, whitelisted CORS, rate limiting, and Zod validation on all write endpoints
- Atomic MongoDB transaction for account deletion

**Stack:** React · Node.js · Express · MongoDB · Recharts
